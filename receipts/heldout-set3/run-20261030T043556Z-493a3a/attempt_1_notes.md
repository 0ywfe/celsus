**Replication script `/work/replicate.py` runs end-to-end (20 min, `pip pandas numpy scipy statsmodels yfinance pyarrow`) and writes `/work/results.json` (125 claims).**

**Sample built:** Yahoo Finance daily OHLCV via `market_data.get_prices` for ETFs SPY/QQQ/DIA as proxies for S&P 500 / Nasdaq-100 / DJIA. Full fetch `2018-01-01→2026-02-28` → actual trading days `2018-01-02→2026-02-27` (2050 bars per ticker). Training `2018-01-01→2022-12-31` = **1259** days/ticker (exact paper count, verified), Testing `2023-01-01→2026-02-28` = **791** days/ticker (exact, first test trade 2023-01-03 last 2026-02-27). Long-only, $100 k, `next-day open` execution, integer shares `floor(cash/(open*(1+4 bps)))`, `4 bps` one-way (`3 bps` + `1 bp` slippage, `8 bps` round-trip), EMA `α=2/(n+1)` `12/26/9` via `pandas ewm(adjust=False, span, min_periods=span)`. Same sample as paper (`missing=0, extra=0`).

**Choices the paper leaves open:** (i) `P*_t = Σ P_i Vol_i σ_i r_i / Σ Vol_i` over `i=t-N…t-1` – **`N` never stated** – we set `N=20` (MA20 trading-month, standard). Other `N` changes VP trades dramatically (SPY 6→21). (ii) `σ_i = STD(High-Low)/Close` – STD of a single `High-Low` is undefined – we implement `σ_i=(High-Low)/Close`; alt `rolling STD(N)` or `STD(20)` is undocumented. (iii) Signal price is `close` (paper ambiguous `Close` vs `adj_close`); we use `close` and note `adj_close` shifts baseline trades 38→39. (iv) HAC lag not stated → Bartlett `lags=5`; bootstrap `1000×5` as stated. (v) Sharpe `√252`, MDD `max(Peak-Value)/Peak`, returns `(V_t-V_{t-1})/V_{t-1}`.

**Deviations vs paper:** Honest replication under stated ambiguities does not reproduce headline totals: SPY baseline 40→38 trades, `13612→9698` PnL; MACD+λ SPY `52689→15300` (29 vs 36 trades); VP-MACD SPY 6→21 trades (`27544→32129`); QQQ VP 21→20 trades (`88324→43119`); DIA VP 13→22 trades etc. Differences attributable to data-vintage/dividend-adjustment, exact EMA warm-up, cost-rounding, and crucially the undocumented `N`/`σ` window. Statistical tests equally sensitive: no pair survives one-sided 5 % in our HAC/wild-bootstrap (e.g. SPY Pair1 `t=0.67 p=0.25` vs paper `1.72 p=0.043`). We do **not** pad/slice to hit paper counts.
