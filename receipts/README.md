# Receipts: the held-out set

Every run of the held-out test (32 papers, two runs each) as it was written: 67 run folders, the 4 runs set aside as infrastructure included and marked. Each folder holds the run's report, its spec of the paper's claims, every script attempt and its notes, the sandbox logs, the comparison, the events and the call log (model, tokens and cost per call). The papers' LaTeX source is left out (arXiv licences); the arXiv id fetches it. Email addresses that turned up in fetched pages or papers are replaced with `[email]`. The development runs are not here.

**Verdict as run** is what each run wrote on the code frozen for the test: the README's headline. **Post-headline replay** re-scores the same stored attempts under the scorer after the post-headline fixes. It is not a fresh test, as the fixes were written after reading these runs. A run with nothing to re-score (a budget stop, or no results) keeps its verdict.
